# Alpha Plotter — demonstração local

Landing page estática em HTML, CSS e JavaScript. Não usa frameworks, backend, formulários com coleta de dados nem serviços pagos. A solicitação de orçamento abre uma conversa no WhatsApp com uma mensagem inicial preenchida.

## Como visualizar

1. Extraia a pasta `alpha-plotter` mantendo a subpasta `assets`.
2. Abra `index.html` no navegador. Para melhor compatibilidade, também é possível servir esta pasta por um servidor HTTP local, por exemplo com `python -m http.server 8000`, e visitar `http://localhost:8000`.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade monocromática e layouts responsivos.
- `script.js`: menu móvel, comparador de imagens e ano automático do rodapé.
- `assets/`: logo e fotografias fornecidas, convertidas para WebP para reduzir o peso.
